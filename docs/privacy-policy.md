# ClipLayer Privacy Policy

Effective date: May 20, 2026

ClipLayer is a Chrome extension that helps users extract structured data from web pages they are authorized to access. This policy explains what data the extension handles and how that data is used.

## Data Handled by the Extension

ClipLayer may process the following data when the user explicitly uses the extension:

- Web page content selected or extracted by the user
- Page URL and page title used to match extraction profiles
- User-created extraction profiles
- Extraction results and run history
- Extension settings

## How Data Is Stored

By default, ClipLayer stores profiles, extraction results, settings, and run history locally in the user's browser using Chrome extension storage and IndexedDB.

ClipLayer does not sell user data. ClipLayer does not share user data with third parties. ClipLayer does not transmit extracted page content to an external server unless the user explicitly configures and starts a feature that sends data to a destination they control.

## Remote Code

ClipLayer does not execute remotely hosted code. JavaScript and CSS used by the extension are packaged with the extension.

## Permissions

ClipLayer requests browser permissions only to provide its core functionality:

- `sidePanel`: display the ClipLayer interface next to the page being processed
- `storage`: save profiles, settings, extraction results, and history locally
- `tabs`: read the active tab URL and title to find matching extraction profiles
- Optional host permissions: run extraction and picker functionality only on pages selected by the user

## User Control

Users choose which pages to process and which fields to extract. Users can remove locally stored extension data by clearing the extension's site data or uninstalling the extension.

## Contact

For privacy questions, contact the publisher using the contact email listed on the Chrome Web Store publisher account.
